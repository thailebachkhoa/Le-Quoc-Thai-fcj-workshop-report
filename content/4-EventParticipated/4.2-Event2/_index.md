# Event Summary Report

### Speakers

- **Nguyen Huynh Son**: Former HUFLIT student, Developer at Endava
- **Ngo Le Tan Huy** - FCAJ Admin
- **Thinh Nguyen** - FCAJ Admin

### Key Highlights

#### SLA and SLA Coordination

- SLA: Service Level Agreement - a commitment from the technical team to non-technical clients -> A crucial component of project management
- Project coordination pyramid:<br> UX (User Experience) -> Business Logic (Corporate Clients) -> Application (Managed by Devs) -> Infrastructure (CPU - RAM, etc.) -> Cloud Service Providers (AWS, Google Cloud, Azure)
- The key takeaway of this session is the slogan: "Applications are usually the part freshers focus on most and inflate the most in a pyramid, whereas number one should always be UX."
- Quoting advice from former AWS CTO: "Plan for failing as things fall all time"
- During the presentation, speaker Son shared a typical case study: errors can happen anywhere, and a minor update can cause system-wide discrepancies. Developers are responsible for providing support within a short timeframe (which the speaker shared was the most stressful part of his previous job).

#### AWS Certification: Competition Insight

- An introduction and guide for the AWS Certified Cloud Practitioner (CLF-C02) exam — a valuable addition to a student's CV
- The exam structure consists of 4 domains: Concepts - Security - Services - Billing -> The content is not overly specialized, making it suitable for beginners
- Summary: This is not a heavily knowledge-intensive test; with the right mindset and a clear strategy, you can easily pass

#### AWS Security Agent

- A newly launched AWS service aimed at enhancing product security
- Personal evaluation of the service demoed by the speaker: "It's an expensive support service compared to the free-tier." However, for large-scale projects, this trade-off is acceptable

### Lessons Learned

- **UX-First Mindset:** Developers (especially freshers) must avoid getting bogged down in application code while overlooking UX, which sits at the very top of the pyramid and brings real value to users.
- **Failure Prevention Mindset ("Plan for failing as things fall all time"):** Issues can stem from the smallest changes. Meeting SLAs requires developers to manage pressure, respond quickly, and design fault-tolerant systems from the start.
- **Effective CV-Building Strategy:** Foundational certifications like AWS CLF-C02 don't require deep technical mastery, but rather a high-level overview and good test-taking strategy — a huge plus for students/juniors.
- **Cost vs. Security Trade-off:** Security is often expensive (like AWS Security Agent), but for large enterprise projects, it is a necessary investment to protect systems and data.
